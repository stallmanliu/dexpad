# DeX Pad

三星 S23 FE 连接 DeX（例如 XREAL One）时，用手机竖屏当触控板。打开 DeX Pad 就能用。

三星自带触控板属于系统，Android 允许它移动光标。普通应用没有这个权限。DeX Pad 使用这台手机上已经存在的调试授权，在手机里自己启动触控服务，不需要再填配对码，也不需要电脑一直连接。

手机重启后，再打开 DeX Pad 即可。如果调试授权被删掉，界面会再提示一次。

## 手势

- 单指移动：移动光标。竖着拿，向右是向右，向下是向下。
- 单指轻点：左键。按住再拖：按住左键拖动。
- 双指轻点：右键。
- 双指滑动：滚动。长按右上角速度键可切换自然滚动 / 传统方向。
- 键盘图标：底部 QWERTY。Shift 点一下作用于下一键，快速点两下锁定。
- 太阳图标：使用时保持屏幕常亮。

## 开发机构建

```bash
./cs_gen/build-dextouch.sh
```

脚本只负责安装并打开应用，不负责长期提供触控服务。
